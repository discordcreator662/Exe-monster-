VOXCRAFT 2027.3.2 - PC EDITION
Coded/made by Igurs0023 - a Voxel Games production

A single C file (voxcraft.c) using only Windows + OpenGL. No other libraries, no image files:
every texture is generated by code.

BUILD AND RUN (Windows)
  1. Install a C compiler once (MinGW-w64):   winget install BrechtSanders.WinLibs.POSIX.UCRT
     then close and reopen your terminal.
  2. Double-click build.bat      (or run:  gcc voxcraft.c -o voxcraft.exe -O2 -mwindows -lopengl32 -lgdi32 -luser32 -lm)
  3. Play: voxcraft.exe

  build.bat also embeds the icon (icon.ico) when windres is available.

CONTROLS
  Mouse ............ look            W A S D ......... move        Space ... jump
  Left mouse ....... break block / attack mob (hold)
  Right mouse ...... use: place block, eat, sleep in a bed, trade with a villager
  1-9 / wheel ...... hotbar            E ............... inventory / crafting
  F ................ fly on/off (creative)         Shift ... sprint (fly faster)
  T or / ........... command console (type /help)  F11 ..... fullscreen
  Esc .............. pause menu

FEATURES
  - Main menu, Settings (render distance, FOV, sensitivity, hand left/right/hidden, VSync), Changelog, Credits
  - Endless world generated as you explore; biomes: Legacy Plains and Spruce Forest
  - Villages with houses, beds and lamps; villagers you can trade with
  - Dimensions: Overworld, Nether, The End (floating islands). Craft a Portal Gate / Void Gate and stand on it
  - Day and night cycle (sun, moon, stars), sleep in a bed at night to skip it and set your spawn
  - Mobs: Boar, Cow, Shade (night), Cinder (Nether), Voidling (End), Villager
  - Creative (unlimited blocks, fly, instant break) and Survival (health, mining time, drops, tools, crafting)
  - First-person hand that swings when you hit or place
  - Save & Quit writes voxcraft_save.dat next to the exe; Continue loads it

COMMANDS (press T or /)
  /time set day|noon|sunset|night|midnight|0-24000    /time query
  /gamemode creative|survival   /fly   /heal   /clear   /pos   /biome   /seed
  /tp x y z    /tp x z    /tp spawn    /setspawn
  /dim overworld|nether|end     /locate village
  /give <item> [count]          e.g.  /give diamond 5      /give oak log 20
  /spawn <boar|cow|shade|cinder|villager|voidling> [count]    /killall    /credits

NOTES
  - Graphics are plain OpenGL (works on any Windows PC with a GPU driver). Vulkan is not part of this edition.
  - This version was tested headless (world generation, villages, mobs, commands, saving, UI logic) but I could not
    run the Windows window/OpenGL layer here. If the build prints an error, send it back and it will be fixed.
